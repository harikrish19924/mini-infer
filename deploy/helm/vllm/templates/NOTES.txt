vLLM is starting. The first start downloads the model weights, so it can take several minutes.

1. Watch it become Ready:
  kubectl --namespace {{ .Release.Namespace }} get pods -l "app.kubernetes.io/instance={{ .Release.Name }}" -w

2. Reach the API:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  {{- range .paths }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ .path }}
  {{- end }}
{{- end }}
{{- else }}
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "vllm.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
{{- end }}

3. Try it (with the port-forward running):
  curl localhost:{{ .Values.service.port }}/v1/models
